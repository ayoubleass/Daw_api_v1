🎵 DAW (Digital Audio Workstation) API
Overview
A RESTful API backend for a Digital Audio Workstation application that handles audio file management, project organization, and music production workflows. This API provides the foundation for creating, managing, and collaborating on music projects.


🚀 Features
🎚️ Project Management
Create, read, update, and delete audio projects
Project metadata (BPM, key, time signature)
Version control for projects
Collaboration and sharing features
